# Ravil 독립 AI 모델·Alt 초과 성능 설계

**2026-10-19 범위 정정:** 현재 제품 전체 목표는 [개인용 세컨드 브레인](product-goal.md)이다.
이 문서는 녹음·전사·학습 생성의 하위 설계로 보존한다. 아래의 Alt 비교·자체 모델·오프라인 수업 검증은 이 하위 작업의 기준이며 제품 전체의 필수 순서나 완료 기준을 대신하지 않는다.

상태: **설계안 — 일부 기반 작업 구현, 실사용 품질 검증 전** (2026-09-30)

한국어 음성 LoRA 실험과 Qwen3-ASR 비교의 실제 결과, 출처·권리 기록 및 잠정 이름
`Ravil-ASMR-0.1-experimental`은 [Ravil-ASMR 개발 기록](ravil-asmr-development.md)에 둔다.
실험 어댑터는 앱 기본 모델이나 공개 출시 모델이 아니다.

## 제품 목표와 독립성의 의미

개인 기록의 입력 경로 중 녹음·자료를 다루는 기능은 전사, 화자 구분, 자료 인식과 출처가 있는 결과까지 Ravil이 관리하는 데이터 흐름으로 처리하는 것을 목표로 한다. Alt·다글로는 과거 자료를 옮기는 입력원이다. AI 실행은 클라우드·Codex·로컬 모델의 연결과 실제 품질을 각각 검증하며, 특정 외부 구독을 모든 기록 기능의 필수 조건으로 삼지 않는다.

**2026-09-26 사용자 결정:** 최종 기준은 ‘모델 가중치를 반드시 처음부터 직접 학습’하는 것이 아니라,
실제 수업에서 **Alt보다 더 나은 Ravil의 독립 AI 경로**를 만드는 것이다. 기존 가중치 활용,
모델 조합, 최적화, 미세조정 가운데 무엇을 쓸지는 같은 평가 자료와 배포 조건으로 결정한다.

| 기준 | 완료의 뜻 |
|---|---|
| 실행 독립 | Alt·다글로가 설치되지 않고 네트워크가 끊긴 Mac에서도 새 녹음 → 전사 → 학습 결과가 생성된다. |
| 배포 독립 | 모든 실행 파일과 가중치를 Ravil이 출처·해시·버전·상업 재배포 조건을 확인한 경로에서 확보한다. Alt 설치 폴더 복사는 배포 경로에서 제거한다. |
| 성능 우위 | 동일한 수업 오디오와 사람이 검수한 정답으로 비교했을 때 전사 오류·과목 용어·환각·시간 정보에서 Alt보다 낫고, 지연·메모리도 사용 가능한 범위다. 학습자료 생성은 출처 정확도를 별도로 검증한다. |

자체 학습·미세조정 가중치는 이 목표를 달성하는 **수단 중 하나**이며 필수적인 이름표가 아니다.
반대로 공개 가중치를 사용하더라도 Ravil의 처리·검색·검증을 포함한 최종 품질이 Alt보다
나으면 후보가 될 수 있다. 어느 경우에도 측정 전에는 ‘Alt보다 우수’하다고 표시하지 않는다.

## 현재 코드와 목표 사이의 차이

- `WhisperTranscriber.swift`는 로컬 `whisper-cli`와 GGML 모델을 실행한다. 시간 정보가 있는 전사 경로는 있으나 긴 실수업·오류 복구·화자 구분·기기별 성능은 최종 검증되지 않았다.
- 2026-09-30 소스의 `script/build_and_run.sh`는 Ravil 캐시에 별도로 받은 공개 Whisper GGML 파일을 SHA-256으로 검사해 번들한다. 이전 DMG는 Alt 설치 폴더에서 복사한 판본이다. 두 파일의 해시는 같으므로 **새로 학습한 Ravil 모델이나 Alt 대비 품질 향상을 뜻하지 않는다.** 엔진은 여전히 빌드 시 Homebrew 설치본을 번들하며, 다른 Mac의 설치 검증은 남아 있다.
- PDF OCR은 Apple Vision을 사용하며, 요약·질의응답·문제 자동 생성의 Ravil 자체 로컬 생성 모델은 없다. 현재 퀴즈 카드는 사용자가 직접 입력한다.
- Alt 읽기 전용 가져오기는 과거 데이터 이전 기능으로 보존하되, 새 강의의 정상 경로에서 Alt DB를 요구하지 않아야 한다.

## 목표 구성

```text
녹음/가져온 오디오 ──> 복구 가능한 청크·음성구간 탐지 ──> Ravil STT ──> 시간 정렬·화자 구분
                                                                  │
PDF/슬라이드 ──> 페이지 추출·기기 내 OCR ──> 출처가 있는 텍스트 구간 ──┤
                                                                  ▼
                                            로컬 검색·자료 검색(RAG) ──> 요약·질의응답·퀴즈 초안
                                                                  │
                                                                  ▼
                                                   원본 쪽/전사 시점 연결·사람 검토
```

### 앱 안의 경계

- **AudioPipeline:** 청크 저장과 재시작 복구를 먼저 보장한다. 전사 실패가 원본 녹음을 지워서는 안 된다.
- **SpeechRecognizer:** 오디오 → 한국어·영어 전사 구간, 시작·끝 시각, 언어와 엔진 버전을 반환한다. 모델 교체 시 DB의 강의 ID와 출처 연결은 유지한다.
- **SpeakerDiarizer:** 화자 ID·시간 범위를 반환하되 STT와 별도 구성으로 둔다. 화자 이름은 추정만으로 확정하지 않는다.
- **DocumentRecognizer:** 페이지 텍스트·OCR 신뢰도·원본 PDF 해시를 보존한다. 손글씨가 불확실하면 검토 대상으로 남긴다.
- **GroundedStudyGenerator:** 검색된 PDF 쪽/전사 구간만 문맥으로 받아 요약·답변·퀴즈 *초안*을 만든다. 각 주장·정답에 출처 ID를 연결하고 근거가 부족하면 답하지 않는다.
- **ModelManager:** 모델별 원본 URL, 라이선스, 해시, 버전, 양자화 방식, 지원 언어, RAM/디스크 요구량을 기록한다. 다운로드 실패·업데이트 실패 시 이전 모델로 되돌린다. 모델 파일은 학습 데이터와 함께 iCloud에 동기화하지 않는다.

Ravil DB에는 최소한 `model_artifacts`(파일 출처·SHA-256·라이선스·호환 기기),
`inference_runs`(모델 버전·입력 해시·설정·시간·성공/실패),
`generated_drafts`(결과·근거 페이지/구간·검토 상태)를 분리한다. 재전사나 모델 교체는
기존 PDF·녹음·검토된 결과를 덮어쓰지 않고 새 실행 기록을 만든다. 요약·퀴즈 화면은
`GroundedStudyGenerator`의 결과를 승인 전 초안으로 표시한다.

### 첫 비교 후보와 결정 순서

| 후보 | 시험할 이유 | 확정 전 확인 |
|---|---|---|
| 독립 출처 Whisper large-v3-turbo + Ravil의 음성 구간·긴 녹음 분할·과목 용어 문맥 | 현재 Alt 모델 계열과 가까워 처리 방식만 바꾼 효과를 분리할 수 있다. | 가중치 출처/양자화 재현성, 같은 오디오에서 오류 감소 여부 |
| Whisper large-v3 | 정확도를 우선한 별도 기준선이다. | 실제 Mac의 속도·메모리 증가와 한국어 수업 정확도 |
| Qwen3-ASR 1.7B (필요시 0.6B) | 공개 구현이 한국어를 지원하고 Apache-2.0으로 배포된다. | Mac에서 완전 로컬 실행·시간 정보·긴 녹음·상업 패키징을 실제 시험 |
| 구간별 후보 비교·어휘 보정 | 어려운 용어/잡음 구간만 더 무거운 모델로 재처리할 수 있다. | 두 모델의 오류가 실제로 보완적인지, 추가 지연이 가치 있는지 |

첫 번째 시도는 **전처리·구간 분할·수업 용어 문맥**을 고정된 평가셋에서 검증하는 것이다.
그 효과가 부족하면 독립 모델 후보를 같은 조건으로 비교하고, 그래도 부족할 때 권리가
확보된 수업 데이터로 미세조정한다. 모델 이름이나 공개 벤치마크 순위만으로 승자를 고르지 않는다.

### Alt와의 동일 조건 평가

- 대표 과목별 한국어 강의, 영어 혼용, 수식·고유명사, 잡음, 화자 전환, 긴 녹음을 포함한 **고정 평가셋**을 만든다. Alt 출력은 비교 대상이지 정답이 아니다. 사람이 검수한 전사본을 별도로 보관한다.
- 같은 오디오·마이크·언어 조건으로 Alt와 Ravil 후보를 돌린다. 원문을 학습에 쓴 파일과 최종 평가는 분리한다.
- 한국어 CER, 영어 WER, 과목 용어 정확도, 무음 구간의 환각, 타임스탬프 오차, 화자 오류, 처리 시간·메모리·배터리를 함께 보고한다. 평균 개선이 일부 과목의 심한 퇴보를 가리지 않도록 과목별 결과도 공개한다.
- 전사만이 아니라 전사 → 출처 검색 → 요약·퀴즈 초안의 실제 사용 결과를 원본 녹음/PDF와 대조한다. 첫 실험 전에는 수치상의 합격선을 꾸며 내지 않고, Alt 기준선 측정 후 목표와 허용 지연을 명시한다.
- 후보는 같은 평가 자료에서 실측한 품질·자원·배포 권한을 함께 만족할 때만 기본 모델로 승격한다. 결과는 ‘구현’, ‘단위 검증’, ‘실제 수업 검증’으로 나눠 보고한다.

## 필요할 때 자체 가중치로 개선하는 경로

1. 한국어 수업 음성, 수식·과목 용어, 영어 혼용 음성의 평가 세트를 먼저 만든다. 원본의 권리와 사용 동의를 기록한다.
2. 독립 조달한 공개 모델을 기준선으로 측정한다. 전사는 CER/WER, 화자는 DER, 요약·문항은 출처 정확성·환각률, 실제 기기에서는 지연·메모리·배터리를 잰다. 임의의 목표 수치로 완료를 선언하지 않는다.
3. 개선 여지가 확인되면 권리가 확보된 데이터로 도메인 미세조정 또는 어댑터 학습을 수행한다. 학교 자료·개인 녹음·Goodnotes 백업을 **기본적으로 학습 데이터로 쓰지 않는다**.
4. 처음부터 대형 기반모델 전체를 학습하는 일은 Alt 대비 측정 결과가 이를 정당화할 때만 데이터·연산·비용 타당성을 검토한다. 미세조정 모델과 처음부터 학습한 모델을 혼동하지 않는다.

## 기기별 실행 범위

- **Mac:** 전체 녹음·전사·OCR·검색·학습 생성의 기준 실행 환경. 현재 기기는 24GB 메모리지만 다른 Mac의 최소 사양은 별도로 정한다.
- **iPhone/iPad:** 동기화된 강의·자료를 오프라인으로 읽고, 기기에 맞는 경량 모델을 선택적으로 실행한다. Mac 전체 모델을 그대로 복사하지 않는다.
- **Apple Watch:** 카드·진도·짧은 요약 중심. 대형 STT/생성 모델 실행은 필수 조건으로 잡지 않는다.

## 출시 차단 조건과 검증

- 깨끗한 Mac에서 Alt·다글로 데이터베이스와 앱 없이, 네트워크를 끊고 실제 수업 녹음부터 출처 있는 학습 결과까지 사용 경로를 확인한다.
- 대표적인 긴 강의, 한국어/영어 혼용, 용어·수식, 잡음, 화자 전환, 중단·재개 사례를 고정해 품질과 자원 사용을 반복 측정한다. 단위 테스트와 패키지 서명은 이 사용 경로의 증거를 대신하지 않는다.
- PDF/전사 원본과 생성 결과를 대조하고, 근거 없는 답변·잘못된 페이지 연결·오래된 판본 출제를 거부하는지 확인한다.
- 상업 빌드의 모든 모델·추론 엔진·폰트·라이브러리에 대해 출처, 라이선스 고지, 재배포 조건과 해시를 기록한다. 새 Ravil 파생 모델은 기반 가중치와 추가 학습 자료의 권리를 별도로 검토한다. 이전 Alt 복사 모델을 이 검토 없이 배포하지 않는다.
- 소개 웹사이트에도 실제 사용 경로에서 검증한 기능만 현재 기능으로 표시한다. 독립모델 후보·연구 목표와 출시 기능을 구분한다.
- 실제 사용자 데이터의 동기화와 백업은 모델 학습·업데이트 경로와 분리한다. 모델 업데이트가 개인 자료나 기존 전사/퀴즈를 변경하지 않는다.

## 이번 설계로 확정하지 않은 것

- 최종 STT·화자 구분·로컬 생성 모델의 이름과 크기. 실제 한국어 수업 평가와 라이선스 확인 전에는 고정하지 않는다. **Alt보다 나은 실사용 품질**은 확정 목표다.
- 자체 학습/미세조정 여부. 실측 결과가 공개 가중치 조합만으로 목표에 도달하지 못할 때 결정한다.
- 유료 클라우드 AI 대체 경로. 상업 상품의 핵심 기능을 외부 구독에 의존시키지 않는 것이 기본안이다.
