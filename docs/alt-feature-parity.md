# Alt 0.12.0 기준 기능 대조

2026-09-24. 사용자가 Alt를 먼저 기준 제품으로 삼고, 이후 별도 지시로 Ravil을 개인화하겠다고
요청했다. 따라서 이 단계에서는 사용자별 새 기능보다 Alt의 기본 탐색·기록 흐름을 우선한다.

## 확인 근거

| 근거 | 확인 범위 |
|---|---|
| 현재 Alt 화면 | 홈, 검색 명령 팔레트, 플러그인 관리·마켓플레이스. 홈에서 워크스페이스/폴더/날짜별 노트, PDF·새 노트·녹음 파일·영상 스크립트 작업, 캘린더 안내, 추천 플러그인, 하단 녹음 옵션을 봄 |
| Alt 0.12.0 앱 번들 문자열·모델 명세 | 노트의 채팅·위키·슬라이드 언급, 설정 범주, MCP/Calendar/외부 연동 문구, Whisper·Gemma·화자 분리 모델 리소스 이름 |
| DSHS 계정 로컬 DB | 폴더 계층·이름·색, 폴더별 노트 수, 노트 유형·제목·날짜와 수입 가능한 전사/요약 메타데이터를 읽기 전용으로 확인. 계정 토큰·설정은 열거나 변경하지 않음 |

번들 문자열에는 오래된 항목과 준비 중인 기능이 섞일 수 있다. 채팅, 위키, 동기화, MCP,
캘린더 등의 문구는 Alt의 실제 현재 계정에서 기능이 동작한다는 검증이 아니다. 설정 내부와
모든 노트 상세 흐름은 이번 실행에서 직접 확인하지 못했다.

## 요청된 과목 표시

2026-09-24에 사용자가 최종 지정한 상위 폴더 목록은 **켈큘, 천문, 미방, 일물, 현물, 국어,
영어, 물실, 프실**이다. 원래 과목 ID와 시간표 값은 바꾸지 않고 Ravil 화면에서만 다음처럼 묶는다.

| 화면 폴더 | 포함되는 원 과목 |
|---|---|
| 켈큘 | 수 I, 수 II, 수 III |
| 천문 | 일지 I |
| 국어 | 독서 |
| 영어 | 영 I, 영 II |
| 미방 | 미방 |
| 일물 | 일물 |
| 현물 | 현물 |
| 물실 | 물실 |
| 프실 | 프실 |

`기타 과목`은 제거했다. 시간표의 연구·자율·창의·체험·활동·음악·체2를 숨기는 UI 결정이며,
그 원자료를 삭제하거나 다른 과목으로 잘못 분류하지 않는다. 원래 강의/노트 제목도 다시 쓰지
않으므로 Alt에 저장된 선생님 표기는 제목에 남고 날짜별 목록에서 그대로 보인다.

### 실제 Alt 폴더 분석과 수정

처음에는 개인 기본 DB `lecture_notes.db`만 읽어 2026년 7월 노트 2건만 발견했다. 그래서 모든
폴더가 0건으로 보였고 시간표의 `수 I`·`독서` 등을 폴더 밑의 자식 항목으로 만든 것은 Alt의
폴더 관리 방식과 달랐다. DSHS 데이터는 같은 Mac의 Alt 계정 PowerSync DB에 있었다.

확인한 Alt 폴더는 모두 `parent_id = NULL`인 **최상위 폴더**다. 선생님 이름은 자식 폴더가
아니라 노트 제목에 들어 있다. DB의 원래 폴더 `캘큘`만 사용자 지정 화면 표기 `켈큘`로
바꿨다. 실제 폴더별 노트 수는 아래와 같다.

| 화면 표기 | Alt 원본 폴더 | 원본 노트 수 | Alt 노트 제목의 선생님 표기 예시 |
|---|---|---:|---|
| 켈큘 | 캘큘 | 2 | 강윤석T |
| 천문 | 천문 | 1 | 배태윤T |
| 미방 | 미방 | 2 | 선생님 표기 없는 `Test Hint`, 슬라이드 노트 |
| 일물 | 일물 | 0 | 없음 |
| 현물 | 현물 | 4 | 김제훈T·조우주T |
| 국어 | 국어 | 3 | 윤소영T |
| 영어 | 영어 | 3 | 김선옥T·이계화T |
| 물실 | Alt에 없음 | — | Ravil 사용자 지정 폴더 |
| 프실 | Alt에 없음 | — | Ravil 사용자 지정 폴더 |

계정 DB에는 노트 18건이 있으며 15건이 위 7개 폴더에, 3건은 폴더 없이 있다. Ravil은
해당 계정 DB를 읽기 전용으로 연 뒤 18건을 자체 DB로 수입한다. 원본 Alt DB나 폴더·노트를
수정하지 않는다. 이 작업은 **같은 Mac의 로컬 계정 DB를 읽는 방식**이며 Alt 클라우드 계정
API, 원격 자동 동기화, iPhone/iPad/Watch 동기화가 구현됐다는 뜻은 아니다.

## 범위와 제약

- 이번 1차 목표는 Alt의 홈·탐색·강의/노트·전사·오디오·자료 흐름을 Ravil에서 가깝게 만드는 것이다.
- 앱 이름 Ravil과 내부 저장소는 유지한다. 사용자가 나중에 개인화 기능을 지정하기 전에는 별도
  Course Memory나 개인 전용 워크플로를 기본 기능으로 확장하지 않는다.
- Google 계정, MCP 서버, 채팅 모델, 시스템 오디오, 화자 분리처럼 계정·권한·추가 모델이 필요한
  기능은 구현 여부를 분명히 구분하며 동작하는 것처럼 표시하지 않는다.
- Alt 조사 도중 설정 진입 시 홈 화면과 표시 중인 노트 묶음이 예상과 다르게 바뀌어 추가 조작을
  멈췄다. 원인은 확인되지 않았고 자료/설정의 값은 수정하지 않았다.
- Computer Use 화면 캡처는 현재 대화에 표시되었지만, 지원 도구에서 로컬 파일 저장을 할 수 없어
  별도 스크린샷 묶음은 만들지 않았다. 따라서 이 문서는 기능 대조 기록이지 저장된 캡처를 갖춘
  완전한 시각 UX 감사 보고서는 아니다.
