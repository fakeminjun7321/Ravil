# Mac 성능 개선 1차 — PDF 처리

현재 우선순위는 [Mac 성능·안정성](mac-first-roadmap.md)이다. AI 자동 복습, 추가 모델 학습, iPad·iPhone 네이티브 공개는 후순위이며 기기 확장은 PWA부터 검토한다.

## 확인한 병목

실제 보관함 DB의 읽기 전용 백업 사본과 462쪽 PDF로 release 빌드의 구성요소를 측정했다. 원본 DB·PDF를 수정하지 않았다. 측정 대상 보관함은 강의 20개, 자료 48개, 전사 구간 10,009개였다.

- PDF 가져오기: 기존 동기 호출 약 4.6초. 호출자가 `@MainActor AppModel`이라 긴 문서의 해시·복사·텍스트 추출 중 화면 스레드를 점유한다.
- PDF 페이지: 매 요청마다 문서를 다시 열고 thumbnail → TIFF → PNG → NSImage 변환을 수행했다.
- 자료 목록 조회는 1ms 미만, 검색은 약 9–14ms, Alt 메타데이터·동기화는 합계 약 27ms였다. 이번 변경에서 SQLite FTS나 전체 동기화 구조를 교체할 근거로 삼지 않았다.

## 구현

- `LocalPDFImporter` actor에서 별도 직렬 DB 연결로 가져오기를 수행한다. 기존 가져오기 코드의 중복 방지, 과목/강의 연결, 해시 검증과 판본 트랜잭션을 재사용한다.
- 화면에는 가져오기 진행 상태를 표시한다. 중복 가져오기는 막고, 기다리는 동안 사용자가 다른 자료로 이동했다면 완료 시 강제로 화면을 되돌리지 않는다.
- `PDFPageRenderer` actor가 문서를 재사용하고 페이지 래스터화 작업을 직렬화한다. 취소된 대기 요청은 렌더 전에 버린다.
- TIFF·PNG 직렬화를 없애고 동일 해상도의 CGImage를 표시한다. 디코딩된 픽셀 비용으로 32MiB 목표/4개 항목 캐시를 사용한다. 경로·수정 시각·파일 크기·inode 변경을 캐시 키에 반영한다.
- 별도 검증 앱은 `RavilVerificationDataDirectory`가 지정된 사본 DB와 독립 번들 ID를 사용한다. 원본 보관함 이전, Alt 자동 가져오기와 Google 계정 복원·자동 동기화를 하지 않는다. 일반 앱에 해당 키가 없으면 기존 보관함 동작을 유지한다.

## 측정 결과

첫 전후 비교 실행의 관측치다. 하드웨어·디스크 캐시·다른 작업 부하에 따라 달라질 수 있으며 GUI 프레임 추적 결과가 아니다.

| 항목 | 기존 | 변경 후 |
|---|---:|---:|
| PDF 가져오기 전체 시간 | 4,499ms | 4,703ms |
| 가져오는 동안 10ms 메인 액터 타이머의 최대 지연 | 4,498ms | 26ms |
| 6쪽 최초 래스터 표시 준비 평균 | 51.9ms | 20.3ms |
| 동일 페이지 즉시 재요청 평균 | 별도 비교하지 않음 | 0.149ms |
| 새 경로의 문서 로드 횟수 / 래스터화 횟수 | — | 1 / 6 |

가져오기 계산 자체가 빨라졌다는 결과가 아니다. 주된 개선은 긴 계산 중 메인 액터를 비워 다른 화면 작업을 처리할 수 있게 한 것이다. 타이머 지연도 실제 스크롤 FPS나 클릭 지연과 동일한 지표는 아니다.

검증 번들의 재측정에서는 가져오기 4,442ms → 4,555ms, 메인 액터 타이머 최대 지연 4,442ms → 1.73ms였다. 페이지 준비 평균은 48.1ms → 19.2ms, 즉시 재요청은 0.138ms였다. 반복 간 부하 차이가 있어 하나의 지연 수치를 모든 상황에 보장하지 않는다.

## 검증

- **Implemented:** 백그라운드 가져오기, 직렬 PDF 렌더러·픽셀 캐시, 진행 상태, 사본 보관함 검증 프로필.
- **Unit/component-verified:** 새 렌더와 이전 렌더의 1200×1600 검사 이미지에서 평균 픽셀 차이 0. 한글·숫자·색상 표시를 이미지로 확인했다. 캐시 재사용, 동일 경로 파일 변경, 범위 밖 페이지, 취소 요청, 과목 연결, 중복 가져오기, 판본 이력·재열기, 손상 PDF 거부 검사를 통과했다. 이미지는 생성한 검사 자료이며 사용자 학습지가 아니다.
- **기존 회귀 검사:** Node 16개, Goodnotes 가져오기/분류/재분류/판본·OCR 검사와 앱 스모크 검사를 통과했다.
- **Build/package-verified:** macOS 26.5 SDK release 빌드, 별도 앱 번들 생성과 ad-hoc 서명 검사 통과. 공개 공증 배포를 뜻하지 않는다.
- **Not verified / 미검증:** 새 창의 실제 PDF 가져오기·빠른 페이지 이동과 화면 전환. 화면 조작은 사용자 허가 후 검증용 보관함으로 확인한다. 일반 설치 앱 교체와 전체 녹음→전사 흐름은 이번 검사 범위가 아니다.

재현 도구: `--mac-performance-check <private-input.json> <report.json>`, `--pdf-performance-regression-check <new-output-directory>`. 전자는 제공된 DB를 다시 복제해 측정한다. 개인 DB·PDF 경로와 결과 원본은 무시되는 `tmp/performance/`에만 저장하며 저장소에 포함하지 않는다.
