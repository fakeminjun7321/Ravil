# Ravil 개발 목표

기준일: 2026-10-19. 사용자가 이 대화에서 정정하고 프로젝트 전체 반영을 요청한 목표다.
이 문서는 과거 학습 앱 계획보다 우선한다. 과거 문서는 당시 구현·검증의 기록으로 보존한다.

> Ravil은 내가 자유롭게 남긴 기록을 AI가 분석하고 정리하며, 필요한 순간에 생각과 행동을 돕는 개인용 세컨드 브레인 워크스페이스다.

## 사용 목적

생각, 경험, 아이디어, 읽은 자료, 계획과 진행 과정을 쉽게 남기고 다시 활용한다.
학습, 개인 프로젝트, 일상, 의사결정은 활용 사례이며 특정 과목이나 시험을 필수로 요구하지 않는다.
사용자의 원문 기록과 선택이 중심이고 AI는 기록을 이해하고 연결하며 도움을 제공한다.

## 핵심 흐름

1. **기록한다.** 분류를 먼저 끝내지 않아도 메모·자료·활동·계획을 남길 수 있다.
2. **AI가 분석하고 정리한다.** 핵심, 주제, 관련 기록, 열린 질문과 다음 행동을 제안한다.
3. **다시 찾아 활용한다.** 키워드와 주제·프로젝트로 찾고, 기록에 질문하고, 다음 작업을 이어간다.
4. **확인하고 정정한다.** AI 해석과 근거 원문을 함께 보고, 채택할 내용과 수정할 내용을 선택한다.

## 제품 원칙

- 원문 하나를 여러 주제·프로젝트에서 연결한다. 내부 호환 키 `subject`/`subjectIDs`는 주제 연결에도 사용한다.
- 주제·프로젝트·마감일은 선택 사항이다. 분류되지 않은 기록도 검색·AI 도움·백업의 대상이다.
- AI 결과와 사용자가 직접 쓴 내용은 구분한다. 재분석은 원문과 수동 태그를 덮어쓰지 않는다.
- 답변·제안·연결은 실제 제공한 기록 ID로 근거를 제한한다. 근거가 없으면 부족하다고 알린다.
- AI가 할 일 추가·기록 수정·외부 일정 등록을 제안할 수 있으며 실제 변경은 사용자가 선택한다.
- 개인화에는 Ravil 안에서 사용자가 남긴 기록·활동·정정을 사용한다. 다른 앱이나 Mac 전체 화면 관찰을 전제하지 않는다.
- 기록 보존·검색은 AI 실패와 분리한다. 모델이나 연결을 바꿔도 원문·자료·연결을 유지한다.
- 학습 기능, PDF 판본, 전사, 시험 범위와 기존 데이터는 재사용 가능한 기능으로 보존한다.

## 개발 판단 기준

기능은 ‘기록하기, 이해·정리하기, 다시 활용하기’ 중 어떤 행동을 돕는지 설명할 수 있어야 한다.
특정 모델 자체 학습, Alt 대비 전사 성능, 시험 복습은 독립적인 하위 작업이며 제품 전체의 완료 기준을 대신하지 않는다.
Codex·로컬 모델·클라우드 AI는 실행 선택지다. 로그인 성공과 실제 생성·출처 정확도·결과 보존은 별도로 검증한다.

## 실제 사용자 경로의 완료 기준

- 자유 기록을 저장하고 재열기 후 원문·첨부·주제·프로젝트 연결을 확인한다.
- 일상·아이디어·프로젝트·학습 등 다른 종류의 기록을 같은 흐름에서 다룬다.
- 기록에 AI 정리와 질문을 요청해 실제 모델 응답·근거 기록·저장된 결과를 확인한다.
- 원문 수정 이후 이전 AI 결과를 현재 원문에 대한 결과로 표시하지 않는다.
- AI 제안 적용 시 사용자의 수동 태그·원문·기존 할 일 진행이 보존되는지 확인한다.
- 일반 프로젝트를 주제 분류 없이 백업·검사·보관하고 원문을 다시 찾는다.
- 클라우드 AI와 Codex·로컬 모델은 실제 연결과 품질을 각각 검증한다. 계약 테스트로 실제 생성 검증을 대신하지 않는다.

검증 표기는 Implemented, Unit-verified, Simulator-verified, Physical-device-verified를 구분한다.
아직 수행하지 못한 실제 사용자 경로는 Not verified / 미검증으로 남긴다.
