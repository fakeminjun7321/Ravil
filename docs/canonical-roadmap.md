# Ravil 공식 로드맵

기준일: 2026-10-19. [개발 목표](product-goal.md)를 기준으로 한다.

> 내가 기록하고, AI가 분석·정리하며, 필요한 순간에 생각과 행동을 돕는 개인용 세컨드 브레인 워크스페이스.

## 제품의 중심

기록 → 분석·정리 → 다시 찾고 활용하기 → 사용자 확인·정정의 흐름을 Mac과 웹에서 연결한다.
학습은 개인 기록의 활용 영역 중 하나다. 과목·시험·시간표 없이도 일상·아이디어·프로젝트 기록을 사용할 수 있어야 한다.
소개 사이트, 작업 공간, Mac 앱과 AI API는 같은 목표와 용어를 사용한다.

## 구현 순서와 검증 기준

| 단계 | 범위 | 확인할 실제 결과 |
|---|---|---|
| 1. 기록 기반 | 자유 기록, 자료 첨부, 주제·프로젝트, 계정별 저장·동기화 | 분류와 마감일 없이 기록을 남기고 재열기해 원문·첨부·연결을 확인한다. |
| 2. 분석·정리 | 핵심 요약, 주제, 관련 기록 연결, 다음 행동 제안 | 실제 AI 결과에 제공한 기록만 인용되고, 원문·수동 태그가 보존된다. |
| 3. 다시 활용 | 기록 검색, 기록에 질문, 근거로 이동, 이전 작업 이어가기 | 프로젝트 이름과 AI 정리로도 기록을 찾고, 질문의 답변에서 해당 원문을 연다. |
| 4. 사용자와 함께 조정 | 제안 검토·선택 적용, 정정, 활동에 근거한 시간 추정 | AI 제안과 직접 입력을 구분하고, 정정·기존 진행을 보존하며 변경을 확인한다. |
| 5. 보존과 기기 연결 | 일반 프로젝트 백업·검사·보관, Mac·웹·PWA 연결 | 분류되지 않은 기록도 보존되고, 계정 격리·충돌·오프라인·복원을 확인한다. |

구현 순서는 목표이며 표 자체가 검증 완료를 뜻하지 않는다. 이미 있는 자료·녹음·학습 기능은 같은 기록 기반에서 계속 사용할 수 있게 보존한다.

## AI 실행 선택지

- 웹은 현재 연결된 클라우드 AI 경로를 사용한다. 선택 기록과 검색·연결로 좁힌 관련 기록을 보낸다.
- Mac의 Codex와 로컬 모델은 별도 연결 경로다. 연결 상태·중단·오류·실제 응답과 저장을 함께 확인한다.
- 모델 이름이나 자체 학습 여부보다 실제 기록에서 유용한 결과와 근거 정확도를 판단한다.
- AI 실패 시 원문·검색·수동 정리·저장은 계속 보존한다.
- 외부 행동이나 일정 등록은 사용자 선택과 기존 권한 범위를 따른다.

## 완료 보고

코드 존재(Implemented), 자동 검사(Unit-verified), 시뮬레이터 경로(Simulator-verified), 실제 기기 경로(Physical-device-verified)를 구분한다.
실제 모델 호출·계정·기기·백업 목적지 검증이 빠졌다면 정확한 범위와 이유를 Not verified / 미검증으로 기록한다.
단위 테스트나 화면 렌더만으로 전체 제품 완료·출시 준비를 선언하지 않는다.

## 기존 작업과 역사

- [이전 학습 앱 로드맵](legacy-learning-roadmap.md): Alt 수집, 과목 분류, Study View, Course Memory, 녹음·전사 단계의 당시 상태를 보존한다.
- [개인 워크스페이스 구현 기록](personal-workspace-2026-10-04.md): 계정·동기화·노트·파일·백업의 기존 작업 기록이다.
- [Mac 우선 범위](mac-first-roadmap.md): 새 목표의 실제 Mac 사용 흐름과 데이터 보존 기준이다.
- [음성·독립 모델 설계](ravil-independent-ai-architecture.md): 녹음·전사·학습 생성의 하위 작업이다. Alt 대비 성능은 이 하위 작업의 연구 기준이다.
- `phase1:*` 등 내부 명령·DB 키·패키지 이름은 호환을 위해 남길 수 있다. 이름 변경을 위해 기존 자료나 검증 이력을 이동·삭제하지 않는다.

운영 배포, 유료 실행, DNS·클라우드 설정 변경은 실제 대상과 영향을 확인하고 별도 승인 후 진행한다.
