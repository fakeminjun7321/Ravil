# Ravil-ASMR 0.6 추가 학습 파일럿 — 2026-10-01

사용자의 요청에 따라 추가 공개 데이터 작업을 보류하고 첫 학습 실험 결과를 보존했다. **이번에는 엔진 코드 변경에 더해 실제 LoRA 가중치를 학습·저장·재로드했다.** 앱 기본 모델 또는 공개 배포판으로 채택하지 않았다.

## 방법

- 기반: `Qwen/Qwen3-ASR-0.6B-hf`, Apache-2.0, revision `7f1569a48a89f3e3f4dc3a5c9d28bddd903bc76c`.
- 학습: 음성 인코더와 원본 가중치를 고정하고 decoder q/v에 rank-8 LoRA, alpha 16, dropout 0.05, 학습률 2e-5.
- 학습 파라미터: 1,146,880개. 2회 학습, optimizer update 50회, adapter tensor 112개가 초기값과 달라짐.
- 학습 쌍: 공개 FLEURS 한국어·영어 정답 96개 + 사용자 허가된 수업의 임시 기계 정답 4개.
- 수업 42구간을 두 인식기로 비교해 7개를 선별했고, 그중 학습 4개·검증 3개로 분리했다. 이 일치는 사람 정답을 증명하지 않는다.
- 공개 검증 24개와 수업 검증 3개를 사용했다. 공개 검증 손실로 2회차를 선택했으며, 최종 확인은 별도 공개 40개(한국어·영어 각각 20개)로 수행했다.
- 원본 녹음·공개 문장 그룹·음성 해시의 학습/검증/시험 중복을 검사했다. 프롬프트·오디오·패딩을 제외한 assistant 정답 토큰에만 손실을 적용했다.
