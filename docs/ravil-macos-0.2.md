# Ravil 0.2.0 — Alt 기준 1차 재구성

## 이번 버전

- Alt 0.12 홈의 정보 배치를 참고해 아이콘 레일, 보관함/과목 폴더, 날짜별 최근 강의,
  중앙 빠른 실행과 하단 녹음 바를 배치했다.
- 빠른 실행에서 PDF 추가, 새 노트, 녹음 파일 가져오기, 녹음 설정으로 이동할 수 있다.
- 로컬 오디오 파일 WAV/MP3/OGG/FLAC를 Ravil 저장소로 복사하고 강의로 등록한 뒤 번들 Whisper로
  전사하도록 연결했다.
- 전사 언어(자동/한국어/영어/일본어/중국어), 영어 번역, 키워드 프롬프트를 선택하고 저장한다.
- PDF를 특정 강의에 직접 연결할 수 있다. 연결 자료의 페이지 미리보기와 페이지 이동을 제공한다.
- PDF 페이지 텍스트를 검색하고 해당 자료를 열 수 있다.
- SQLite 원본, Alt의 개인 노트, 녹음은 DMG에 포함하지 않는다.

## Verification

- `swift build -c release` 통과.
- `script/build_and_run.sh --build`가 0.2.0 앱 번들을 만들고 ad-hoc 서명을 완료했다.
- `script/package_dmg.sh`에서 앱 서명 검사와 `hdiutil verify`가 통과했다.
- 실제 Ravil 창, 파일 선택 후 저장, 언어별 실사용 전사, 번역 결과, 마이크 녹음은 이번 빌드에서
  직접 조작해 확인하지 않았다.
- 현재 UI 조사에서 Alt 홈·명령 팔레트·플러그인 관리/마켓플레이스를 확인했다. Alt 설정 화면
  진입 중 라이브러리 화면이 뜻밖에 전환돼 추가 화면 조작을 중단했다. 화면 전환 원인은 미확인이다.

## Alt 기능 중 아직 없는 것

노트 채팅, Google Calendar, MCP와 외부 플러그인, 영상 스크립트 가져오기, 시스템 오디오 녹음,
화자 분리, 여러 기기 동기화는 구현하지 않았다. 이 기능은 현재 코드에 UI만 만들어 동작하는 것처럼
보이게 하지 않았으며, 관련 분석 수준과 우선 이식 범위는 `alt-feature-parity.md`에 적었다.

현재 DMG는 Apple Silicon용 개인 개발 빌드이며 ad-hoc 서명 상태다. 다른 Mac의 Gatekeeper 승인과
실제 설치/사용은 검증하지 않았다.
