# Ravil 0.5.0 구현·검증 범위 (2026-09-25)

이번 빌드는 사용자가 요청한 실제 화면 검증, Goodnotes 갱신·비교, 기기 내 OCR, 새로고침·PDF·검색·저장 공간 최적화를 대상으로 한다. **구현, 자동 검사, 사용자 화면 확인을 구분한다.**

| 요청 | 구현·관찰 | 아직 필요한 검증 또는 결정 |
|---|---|---|
| 실제 화면 | Ravil 프로세스 실행은 확인. 새 자료 상세에는 과목·판본 선택·변경 요약·OCR 상태가 표시되도록 구현 | Computer Use가 `failedToCreateImageDestination`(-10005)를 반환해 0.5.0 설치·화면·클릭 경로는 미검증. 다른 UI 도구로 우회하지 않음 |
| Goodnotes 갱신·비교 | 중간고사 Drive 폴더를 다시 읽어 기존 2파일의 v2, 신규 2파일을 수입. 이전 PDF 보존. 쪽수와 페이지 그림 해시로 변경 위치를 비교하고 앱에서 이전 판본을 고를 수 있도록 구현 | 수집은 Codex 연결 도구를 통한 1회 작업. Ravil 자체 Google 로그인/자동 감시는 미구현. Mac에 Google Drive 동기화 폴더·Ravil OAuth 클라이언트가 없어 연결 방식 선택과 계정 설정 필요 |
| 기기 내 OCR | Apple Vision의 한국어·영어 정확 모드로 현재 판본의 저텍스트 페이지 148쪽 처리. 원본과 별도 표, 모두 `needs_review`; 검색 결과에도 `OCR 미검토` 표시 | 모든 필기·수식 인식 정확도와 실제 앱 표시 미검증. 빈 템플릿 2문서는 OCR·퀴즈 원천에서 제외 |

| PDF 페이지 | 기존 156쪽 PDF의 1200×1600 썸네일 생성은 관찰한 4페이지에서 10~33ms. 새 코드는 렌더를 백그라운드로 옮기고 최대 32MB의 이미지 캐시·취소 처리를 추가 | 화면 반응과 이미지 품질은 0.5 실제 창에서 미검증 |
| 검색 | OCR 결과 검색을 추가하고 최신 Goodnotes 자료 판별에 DB 인덱스를 사용. 5회 로컬 측정의 중앙값: `수열` 4.6ms, `파동` 6.9~7.4ms, `추천` 7.4ms 수준 | 현재 느리다는 근거가 없어 FTS5 전환은 하지 않음. 실제 UI 입력·대규모 자료에서 재측정 필요 |

## 현재 자료 및 검사

- 중간고사 최신 25문서/1,254쪽, 전체 27개 보존 판본, OCR 148쪽. 새 PDF 4개의 Ravil 보관본 SHA-256이 DB 해시와 일치한다. 새 4개를 다시 수입해도 신규 버전 0개였다.
- 같은 쪽수의 실제 갱신: 현물 조우주T 정리 v1→v2에서 그림 변경 2·3쪽, 미방 학습지 v1→v2에서 18개 쪽이 변경. 현물 2쪽은 이전·현재를 직접 렌더링해 추가 필기를 확인했다. PDF 바이트/그림 변경은 확인되지만 변경 이유를 자동으로 `주석`이라고 확정하지 않는다.
- 국어 윤소영T 학습지 1쪽은 OCR 1,552자, 평균 신뢰도 0.91로 대표 문구를 원본과 대조했다. 148쪽 전체의 정답성은 검토되지 않았다.
- `swift build`, `node --test` 16개, `--smoke-test`, `--alt-folders-check`, `--goodnotes-import-check` 통과. `--goodnotes-import-check`는 판본·페이지 그림 변경·Drive ID/이름 변경·경로 충돌·롤백·OCR 중복 방지를 검사한다. 손상 PDF를 거부하는 검사에서 CoreGraphics의 예상 경고가 한 번 출력된다.
- 0.5.0 앱 서명과 DMG 무결성 검사가 통과했다. DMG를 읽기 전용·비표시로 마운트한 뒤 내장 앱의 서명·Goodnotes 검사·번들 Alt 모델 선택을 확인했다. 이것은 설치·실제 화면 경로의 증거가 아니다.
- 수입 전 백업: `~/Library/Application Support/Ravil/Backups/ravil-before-goodnotes-update-20260925.sqlite`, `ravil-before-ocr-20260925.sqlite`. 둘 다 생성 후 무결성 검사 `ok`를 확인했다. Ravil 현재 DB 무결성도 `ok`.

## 배포 경계

0.5.0 DMG는 Apple Silicon 개인 개발용이며 ad-hoc 서명이다. Developer ID 서명·공증, 다른 Mac 설치, iPhone/iPad/Watch 동기화는 검증되지 않았다. Alt의 로컬 Whisper 모델 원본과 Drive 원본은 변경하지 않았다. 새 PDF 다운로드와 비교용으로 생성한 임시 파일만 제거했으며 Ravil의 보존 PDF·DB에는 영향을 주지 않았다.
