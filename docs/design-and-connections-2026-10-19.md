# RAVIL 원문 중심 웹과 Mac AI 연결 개발 기록

2026-10-19. 사용자가 선택한 **1번: 원문 + AI 맥락 패널**을 구현했다. 이전의 어두운 네 칸 화면과 3D R 조각을 기본 화면으로 사용하지 않는다. 제품 목표는 `product-goal.md`를 따르며, 학습을 포함한 일상·생각·경험·개인 프로젝트를 같은 기록 흐름으로 다룬다.

## 구현 범위

- 소개, 로그인·가입, 작업 공간을 따뜻한 흰색 종이·짙은 녹색 잉크·얇은 구분선으로 맞췄다. 글씨 크기는 소개 제목 41px, 보조 페이지 39px, 문서 제목 28px, 작업 UI 12–13px, 본문 데스크톱 15px/모바일 16px이다. 작은 본문·출처의 대비를 보강했다.
- 탐색을 하나의 사이드바로 합치고 중앙에 원문, 오른쪽에 AI의 정리·연결·다음 행동을 배치했다. 좁은 화면에서는 탐색과 AI 맥락을 별도 패널로 연다. `/정리`, `/질문`, 검색과 아이콘 도구, 키보드 탭 이동을 유지한다.
- AI 결과와 근거를 원문과 구분하고, 태그·할 일은 선택해서 반영한다. 원문이 바뀌면 이전 분석을 현재 결과로 표시하지 않는다. 웹의 AI 제공자는 실제 클라우드 경로인 RAVIL AI이며, 브라우저에 작동하지 않는 Codex·로컬 모델 선택기를 넣지 않았다.
- 소개 입력은 로그인 이후 작성 중인 기록으로 이어진다. 들여쓰기·빈줄·끝 공백을 보존하며, 임시 저장 실패 시 이동하지 않고 입력을 유지한다. 소개의 제품 예제와 AI 결과는 설명용임을 명시했다.
- Mac에 Codex 및 Ollama·LM Studio 호환 서버 설정, 모델 선택, 응답 중단, 명시적인 새 노트 저장을 추가했다. 기록 도움은 별도 대화를 사용하므로 다른 기록과 일반 Codex 대화를 자동으로 섞지 않는다. 선택한 기록이 바뀌거나 계정이 바뀌면 응답을 원문의 현재 결과로 저장하지 않는다.
- Mac의 클라우드 AI 응답은 웹과 같은 원문 SHA-256을 대조한다. 동기화 실패·수정 충돌·다른 계정·다른 원문 응답은 거절한다. 주제 없는 프로젝트·보관한 프로젝트 이름 검색, 여러 연결 유지, 활동 시간 중앙값도 확인했다. AI 태그를 반영해도 현재 분석을 유지하고, 원문·연결이 바뀔 때 이전 결과로 바꾸는 기준을 웹과 맞췄다.

## Mac 연결의 실행 범위

Codex는 설치된 실행 파일의 App Server와 기존 계정을 사용한다. 사용자 설정 파일을 수정하거나 인증 파일을 복사하지 않는다. 자식 프로세스의 명령행 설정으로 셸·Code Mode·앱·브라우저·플러그인·이미지·메모리 기능과 웹 검색을 제한한다. 사용자 MCP 이름을 읽어 각각 비활성화하고, 실제 적용 설정과 도구 목록을 확인한 뒤에만 전송을 허용한다. 읽기 전용 샌드박스 자체가 파일 읽기를 전부 금지한다고 해석하지 않는다. CLI에서 변환할 수 없는 MCP 이름은 연결을 거절한다.

로컬 서버는 `localhost`, `127.0.0.1`, `::1`의 `/v1` 경로만 허용한다. 리디렉션을 따라가지 않고 인증 키는 메모리에만 유지한다. 서버 내부의 모델 실행 위치까지 강제하는 기능은 아니다. 실제 확인에는 기존 `qwen3:4b-instruct`를 사용했으며 모델을 새로 다운로드하지 않았다.

## 검증 자료

웹의 선택 시안, 공식 제품 7개 조사와 출처는 `apps/website/design/second-brain-2026-10-19/RESEARCH.md`, 구현 화면과 검증 JSON은 같은 폴더의 `implemented/`에 있다. `workspace-mobile-ai-fixture.png`의 AI 내용은 테스트 응답을 사용한 실제 렌더이며 라이브 모델 품질의 증거가 아니다.

- `entry-verification.json`: 소개 → 로그인 → 원문 저장·D1 재조회, 임시 저장 실패에서 원문 유지.
- `browser-verification.json`: 실제 로컬 저장·백업 및 AI 계약의 전체 경로.
- `mobile-commands-verification.json`: 빈 `/질문`, `/정리`의 패널 표시와 탭 키보드 이동.
- `public-pages-verification.json`: 소개·계정·기능·안내·개발 소식의 두 화면 크기와 가로 넘침 검사.
- Mac 자료: `output/macos-connections-2026-10-19/`의 로그·구성 검사·개발 빌드. 최종 앱은 검사한 Debug 실행파일을 넣은 0.7.0 개발 빌드이며 ad hoc 서명 검사도 통과했다. 원래 설치된 앱과 사용자 데이터를 교체하지 않았다.
- `workspace-offscreen.png`: 실제 SwiftUI를 창 없이 렌더링한 시각 검사. 화면 크기 1250×850pt에서 AI 메뉴의 과도한 폭을 수정했다. 입력·버튼을 조작한 네이티브 사용자 경로 증거는 아니다.

## 재현

현재 Mac의 기본 macOS 27 SDK에는 기존 SwiftUI 매크로 플러그인 오류가 있다. 프로젝트에 기록된 26.5 SDK를 명시해 검사했다. CLT 환경에는 XCTest 모듈이 없어, 저장소의 기존 방식대로 UI를 시작하지 않는 `--connection-check` 검사를 사용한다.

```sh
swift build --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk
.build/debug/Ravil --connection-check "$PWD/script/fixtures/ravil-connections"
```

`RAVIL_VERIFY_LIVE_CONNECTIONS=1`을 주면 실제 Codex 메타데이터 확인과 기존 Ollama 모델의 합성 질문 1회를 추가한다. Codex의 실제 모델 생성은 이 검사에 포함하지 않는다. 키·토큰·실제 기록은 로그나 증거 파일에 넣지 않는다.

## 반영 상태

로컬 검증본이다. 새로운 AI 응답 계약을 쓰므로 운영 반영 시 웹과 Cloudflare Worker를 함께 검토해야 한다. 배포, 실제 계정 로그인 경로, 라이브 AI와 목적지 결과는 별도 확인한다. 개발 빌드를 생성한 사실과 사용자가 설치·실행한 사실도 구분한다.
