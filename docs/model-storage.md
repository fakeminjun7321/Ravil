# Ravil 모델 저장 정책 · 현재 상태

2026-10-22 후속 사용자 결정에 따라 **과거 가중치·대형 압축본 대신 개발 과정과 재현 방법을 보존**한다. 별도 Ravil Ai 프로젝트는 대상이 아니다.

현재의 상세 기준·모델별 개발 흐름은 [모델 개발 이력](model-research-history.md), 재확보·재생성 절차는 `config/model-research-recipes.json`에 있다.

## 현재 보존

- `research/models/`: Qwen3-ASR 1.7B 6비트·0.6B 8비트, Qwen 강제 정렬기, Parakeet BF16, Silero VAD.
- `research/experiments/`: 작은 최종 Whisper v1 LoRA와 Qwen 선택 epoch 2 LoRA 각 한 벌. 합계 약 4.68MiB.
- `research/evaluations/`: 과거 평가 결과.
- `research/history/2026-10-22-record-only/`: 기반·데이터 revision, SHA-256, 코드·의존성 사본, 설정·로그·평가, 삭제 검증 기록. 개인 전사·경로가 포함될 수 있어 Git에서 제외한다.
- `research/model-catalog.json`: 보존 또는 기록 대체 상태.

원본 녹음, 학습·평가 데이터, 가상환경, 기존 Ravil 앱·사용자 데이터와 다른 작업 변경은 보존했다. 기존 tmp 위치의 상대 심볼릭 링크도 유지한다. 단, 삭제된 과거 후보 가중치를 지정하는 명령은 재확보 전까지 실행할 수 없다.

## 이번 후속 정리 결과

대형 압축본 2개, 과거 Qwen 4비트·Redux, 초기/중간 학습 가중치, Whisper 병합·GGML 출력 등 **10개 파일, 8.319GiB**를 삭제했다. 소스·설정·평가 등 개발 기록 약 **21.87MiB**를 남겼으며, 새 기록 폴더를 뺀 추가 순 감소는 약 **8.30GiB**다. 작은 색인/안내 파일 변화는 이 계산에서 제외했다.

삭제 전 파일별 해시·추적 여부·열린 핸들을 확인했고, 삭제 후 현재 후보·최종 어댑터·앱 모델·기존 작업 파일의 해시를 대조했다. 구체적인 경로와 결과는 `research/history/2026-10-22-record-only/deletion-result.json`에 있다. 외부 업로드·운영 서비스 요청은 0회다.

## 앞선 압축 단계는 과거 이력

앞선 단계에서는 원본 7.746GiB를 6.366GiB 압축본으로 보관하고 실제 압축 해제 검증을 했다. 이후 사용자가 개발 기록 중심 정리를 요청했으므로 **그 압축본 두 개도 삭제했다**. `model-archives.noindex/2026-10-22/`에는 당시 manifest·검증 기록만 남아 있다. 이전 검증 JSON은 그 당시 상태이며 현재 압축본이 남아 있다는 뜻이 아니다.

기존 `manage_storage.py restore-cache`와 `restore-parakeet` 명령은 폐기 안내를 반환한다. 인터넷 없는 전체 복원은 더 이상 제공하지 않는다.

## 재확보·재생성의 한계

공개 기반 가중치는 고정 revision에서 다시 받아 기록된 해시와 비교한다. 다운로드 가능 여부는 이번에 확인하지 않았다. 자체 학습 결과는 소스·데이터·설정·seed로 절차를 재실행할 수 있지만, 동일한 가중치 바이트나 같은 평가값을 보장하지 않는다. 그래서 최종 작은 어댑터만 유지한다.

**Not verified / 미검증:** 외부 재다운로드, 재학습·재변환의 결과, 모델 추론, 앱의 녹음→전사→저장 경로. 이번 작업은 파일 정리와 개발 기록 보존의 검증이다.
