# Ravil 0.6.2 Mac 검증 기록 (2026-09-26)

## 이번 변경

- Ravil 녹음·가져온 오디오는 첫 전사 후에도 언어를 고르고 **다시 전사**할 수 있다. 현재 전사와 검색은 새 실행을 보여 주고, 이전 전사 구간·기존 근거는 `transcript_superseded_segments`로 보존한다. 빈 결과나 잘못된 타임스탬프는 저장을 거부한다.
- 각 전사 실행의 언어·엔진·모델 파일명·프롬프트를 별도 출처 기록으로 남긴다. 원시 JSON 출력 파일명도 매 실행마다 고유하게 만들어 이전 파일을 덮어쓰지 않는다.
- GGML BLAS·Metal·CPU 백엔드를 앱에 함께 넣고, 번들 전사 프로세스의 현재 디렉터리를 백엔드 폴더로 설정했다. 빌드 스크립트는 각 플러그인의 Homebrew 동적 링크를 검사하고 재서명한다.

## 실제 Mac에서 관찰한 결함과 분리 검사

- **언어 자동 감지:** `say`로 만든 약 5초 영어 문장을 0.6.1 번들에 `auto`로 입력하자 영어를 한글 발음으로 전사했다. 동일한 WAV를 `en`으로 지정하자 영어 문장으로 전사됐다. 따라서 모델이 영어 전사를 전혀 못 하는 것은 아니며, 이 짧은 입력의 자동 언어 판별이 잘못됐다. 0.6.2는 재전사 언어 선택을 제공하지만 자동 판별 자체의 정확도 개선은 아직 미검증이다.
- **런타임 의존성:** 0.6.1에서 `whisper-cli`가 Homebrew의 GGML 백엔드를 로드하는 것을 발견했다. 처음 시도한 `GGML_BACKEND_PATH=<폴더>`는 잘못된 가정이었다. GGML은 이를 단일 플러그인 파일로 해석했고 기존 Homebrew 백엔드를 먼저 로드했다. 0.6.2는 앱 내부 플러그인을 현재 디렉터리에서 찾도록 바꿨다.
- Homebrew GGML 플러그인 폴더 읽기를 거부한 제한 실행에서 0.6.2의 BLAS·Metal·CPU 백엔드가 앱 번들 경로로 로드됐고, 전사가 완료됐다. 같은 제한 아래 DMG 내부 `Ravil` 실행 파일의 `--transcription-check ... en`도 타임스탬프 포함 결과를 반환했다. **다른 물리적 Mac에서 Homebrew 없이 설치한 검사는 아니다.**

## 검증 수준

- **Implemented:** 재전사 언어 선택, 전사판 이력 보존, 번들 GGML 백엔드.
- **Unit-verified:** `swift build`, `--smoke-test`에서 구판 구간·근거 보존과 최신 검색만 노출되는 동작, Goodnotes/시험 범위 검사, Node 테스트 16개 통과.
- **Bundled headless check:** `dist/Ravil-0.6.2-arm64.dmg`를 읽기 전용 마운트해 내부 앱 버전 0.6.2, `codesign --verify --deep --strict`, 기본 검사와 Homebrew 백엔드 차단 상태의 전사 검사를 통과했다. DMG SHA-256: `7bdd8c9981365e75ea7cc6b993b88a9fb7f22ee62ca8776abe9066b44ff610d7`.
- **Not verified / 미검증:** 실행 중인 0.6.1 화면을 종료·교체하지 않았다. 0.6.2 자료·강의·재전사 화면과 녹음 → 재전사 → 검색 전체 경로는 직접 조작하지 못했다. 화면 도구가 다시 `failedToCreateImageDestination (-10005)`를 반환했고 재연결 시 `failed to write kernel assets`로 실패했다. 다른 자동화로 우회하지 않았다.
- 2026-09-26 확인 시 `dist/Ravil-0.6.1.app`와 별도의 구버전 `dist/Ravil.app`(0.3.0)이 동시에 실행 중이었다. 같은 번들 ID의 두 앱을 사용자가 혼동하거나 같은 DB를 볼 가능성은 있으나 화면 오류의 원인이라고 단정하지 않는다. 저장되지 않은 사용자 작업을 보호하기 위해 구버전 종료는 승인 전까지 하지 않았다.
- **Not verified / 미검증:** 빌드 시 모델 파일은 아직 Alt 설치 폴더에서 복사한다. 상업 배포용 독립 모델 출처와 Alt 대비 품질 우위는 확인되지 않았다. Google 실계정 자동 수집·Apple 기기 간 동기화도 별개다.
- **Distribution:** 앱 서명은 ad-hoc이다. `spctl --assess`는 `rejected`였으며 Developer ID 공증 배포판은 아니다.
