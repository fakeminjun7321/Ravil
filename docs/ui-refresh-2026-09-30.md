# Ravil UI 정리 · 2026-09-30

공부 자료를 다시 찾고 읽는 화면에 맞춰 제목, 목록, 읽기 영역을 중심으로 정리했다. 기존 과목 구분과 자료·강의·노트·시험 기능은 유지한다.

## 변경

- 아이콘 레일과 폴더 패널을 하나의 사이드바로 통합했다. 주요 메뉴에는 이름을 표시하며, 홈과 중복되는 최근 강의 목록은 사이드바에서 제거했다.
- 홈의 큰 퀵 액션 카드와 안내 문구를 제거했다. 최근 강의와 자료를 먼저 배치하고, 가져오기와 새 노트는 `추가` 메뉴에 모았다.
- 자료·강의 목록은 제목과 보조 정보 중심으로 줄였다. 목록 폭과 노트/전사 영역 높이는 네이티브 분할선으로 조절할 수 있다.
- 상세의 큰 아이콘, 과한 제목, 반복 카드와 설명을 줄였다. 자료 판본·OCR·분류·변경 비교 기능과 요약의 근거·검토 상태는 유지했다.
- 노트는 제목과 평평한 편집면으로 정리했다. 녹음의 세부 전사 옵션은 접을 수 있고 활성화된 번역·키워드는 접힌 상태에도 표시한다.
- 설정과 Codex의 설명을 줄이되 데이터 전송·권한·대화 보존 안내는 남겼다.

저장소는 작업 시작 시 커밋 없이 전체 소스가 미추적 상태였다. 기존 파일을 커밋하거나 초기화하지 않았고, 위 사본과 비교해 이번 변경 범위를 확인했다.

## 검증 범위

**Implemented**: UI 소스 변경 및 최종 앱 번들 생성. 릴리스 빌드와 `codesign --verify --deep --strict` 통과.

**Unit-verified**: 번들 실행 파일의 `--smoke-test`와 `--study-check` 통과. 임시 DB를 사용해 노트·강의 메모·전사·검색·PDF 보관·시험 범위·이전 판본 보호를 검사한다. 실제 마이크 녹음, 실제 Alt/Drive 동기화, 사용자 데이터 저장 경로를 검증한 결과는 아니다.

격리된 SwiftUI 렌더에는 한국어·영어 제목, 강의·노트와 생성한 PDF를 사용했다. 앱 소스의 뷰를 복사하되 모델 초기화와 경로를 임시 데이터로 분리했고, Google 연결과 자동 동기화는 실행하지 않았다. 1240×820pt 및 980×680pt, 밝은/어두운 모드를 확인 대상으로 삼았다. 숨긴 NSWindow만 사용했고 전경 활성화는 하지 않았다. 직접 렌더한 380×680pt PDF·강의 상세에서는 한글, 컨트롤과 생성한 PDF의 배치가 확인되었다. 홈·녹음의 본문은 두 크기와 밝은/어두운 모드에서 확인했다.

**Not verified / 미검증**: 실제 앱의 클릭·키보드 탐색, 분할선 드래그, 저장·녹음 사용자 경로. 네이티브 사이드바의 선택 색상과 작은 창의 전체 분할 배치는 오프스크린 캡처에서 표시 한계가 있어 합격으로 판단하지 않는다. 모의 데이터 렌더를 실제 사용자 데이터나 외부 연동 검증으로 취급하지 않는다.

## 빌드

현재 설치된 기본 macOS 27 SDK는 CLI 환경에서 `SwiftUIMacros` 플러그인을 찾지 못했다. 설치되어 있는 26.5 SDK를 명시해 빌드했다. 시스템 SDK 설정은 변경하지 않았다.

```sh
RAVIL_SWIFT_SDK=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk ./script/build_and_run.sh --build
```

`script/build_and_run.sh`에는 선택적 `RAVIL_SWIFT_SDK` 인자를 추가했다. 기본 실행 동작은 유지한다. 빌드·서명 검증과 실제 전경 앱 검증은 별개다.
