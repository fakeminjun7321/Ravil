# 수업 작업 공간과 세컨드 브레인

## 범위

2026-10-03 요청: 수업 통합 화면, 녹음 시각·PDF·메모 연결, 실시간 전사, 녹음 제어, 전사 수정, 시스템 오디오, 화자 구분, 내보내기 및 여러 자료를 종합하는 AI 답변. 실제 마이크 테스트는 수행하지 않는다.

## 구현

- 강의 노트 화면에서 PDF·메모·중요 구간·전사를 함께 사용한다. 기존 요약 탭을 유지한다.
- 북마크는 강의 ID, 원본 녹음 시각, 정확한 PDF 판본 ID·페이지와 메모를 저장한다. 재전사 후에도 유지한다.
- 마이크 선택, 컴퓨터 소리 또는 두 입력 혼합, 음량 표시, 일시정지·재개와 전역 녹음 바를 제공한다. ScreenCaptureKit 권한은 사용자가 실제 시스템 오디오 녹음을 시작할 때 요청한다. 영상 프레임은 저장하지 않는다.
- 두 입력은 직렬 큐에서 16kHz 모노로 변환한다. WAV를 디스크에 연속 저장하고 헤더를 갱신한다. 300ms 입력 지연 버퍼를 두고 일시정지 시간은 녹음 시각에서 제외한다.
- 로컬 Whisper로 최대 8초 창의 전사를 3초 간격으로 갱신한다. 전사 작업은 하나씩 실행하고 대기 중인 미리보기는 최신 창만 보존한다. 미리보기에는 누락·중복이 있을 수 있으며 전체 원본은 별도로 저장한다. 종료 후 전체 녹음을 전사해 보정한다. 추론마다 모델을 로드하는 현 단계는 상주 엔진보다 지연·전력 면에서 불리할 수 있다.
- 전사 내용·화자를 수정하고 수정 이력을 저장한다. 음향 스펙트럼 기반 화자 후보 군집화는 실험 기능이다. 학습된 화자 임베딩 모델이나 화자 신원 인식이 아니며 실제 교실 정확도는 미검증이다. 사용자가 예상 화자 수와 이름을 검토한다.
- Markdown, PDF, SRT, WebVTT, 원본 녹음 내보내기를 제공한다.
- 세컨드 브레인은 강의별 또는 전체 강의·PDF·OCR·개인 노트에서 키워드로 근거를 찾는다. 최대 6개 발췌를 선택·검토한 뒤 기존 Codex 연결로 종합 질문을 보낸다. 답변, 질문, 당시 근거 발췌와 원본 위치를 로컬 DB에 저장한다. 관련 없는 근거 번호는 경고한다. 인용 번호의 존재가 답변의 사실성을 보장하지는 않는다.
- 현재 자료 검색은 로컬 키워드 검색이며 임베딩 기반 의미 검색은 아니다. 각 근거는 최대 1600자 발췌로 전송된다. 새 API 키를 만들거나 저장하지 않고 설치된 Codex의 기존 로그인 경로를 사용한다.

## 재사용 출처

사용자 소유 `fakeminjun7321/live-translator`, 리비전 `478ddbac514a9c619fa2b5a30630b41d5796808f`의 `src/renderer/capture.js`, `src/lib/stt.js`, `src/lib/wav.js`를 읽었다. 해당 저장소 package.json은 MIT로 표시된다. 단일 추론 작업과 최신 부분 결과 우선 구조를 참고해 Swift로 새로 구현했다. Electron 코드·바이너리·인증 설정은 복사하지 않았다.

공개 `live-translator-app`의 리비전 `f44e340f76875edf28b0cdee9f7524845cc0038a`는 정적 배포 파일 중심이므로 오디오 실행 코드를 가져오지 않았다. 기존 Whisper 모델·실행기의 출처·라이선스는 그대로 유지한다.

## 검증 상태

- **Implemented:** 위 데이터·서비스·화면 경로.
- **Unit-verified:** 생성 WAV의 체크포인트·혼합·무음 보존, 생성한 48kHz 버퍼의 16kHz 변환과 일시정지 5초 제외, 북마크·전사 수정 이력·재전사 시 보존, 여러 자료 검색, 근거 스냅샷 재열기, Markdown/PDF/SRT/VTT 출력. 합성 톤 군집화 검사는 알고리즘 실행 검사이며 실제 화자 정확도 검사가 아니다.
- **로컬 모델 구성요소 검증:** 배포 번들 Whisper에 합성 한국어 WAV를 넣어 실시간 미리보기 경로, 전체 녹음 기준 타임스탬프와 임시 파일 정리를 확인했다. 실제 마이크는 열지 않았다.
- **화면 렌더 범위:** 비표시 창에서 PDF·메모·근거 목록 배치를 확인했다. macOS 네이티브 컨트롤 일부가 이 캡처 방식에서는 흰색으로만 나와 버튼 글자·색상 검수는 미검증이다. 이 렌더를 실제 GUI 검증으로 취급하지 않는다.
- **실서비스 구성요소 검증:** 생성한 자료 2개만으로 Codex 요청 1회를 수행했고 두 근거를 인용한 답변이 저장·재열기됐다. 개인 보관함은 전송하지 않았다.
- **Not verified / 미검증:** 실제 마이크, 시스템 오디오 권한·실수집·장치 분리, 교실 화자 정확도, 장시간 실시간 지연·발열·배터리, 전경 GUI 조작 전체. 마이크 테스트는 사용자 요청으로 제외했다.

검사 명령: `--classroom-check <new-folder>`, `--brain-integration-check <new-folder>`(실제 Codex 요청 1회), `--live-preview-check <generated.wav> <new-folder>`, `--classroom-render-check <output-folder>`(사본 프로필 전용 비표시 렌더).

## 2026-10-04 후속 점검

새 녹음 시작 시 이전 강의 ID·시간·음량을 초기화해 DB 등록 실패가 이전 강의와 연결되지 않도록 했다. 화자 이름 일괄 변경은 하나의 트랜잭션으로 묶고, 중간 SQL 실패를 주입해 화자 값과 수정 이력이 함께 되돌아오는 검사를 통과했다. 기존 공개 0.6.3과 설치 앱은 이 변경으로 교체하지 않는다.
