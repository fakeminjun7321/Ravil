# Alt 앱 실화면 확인과 Ravil 적용

Alt v0.12.0의 현재 홈·검색 명령 팔레트·플러그인 관리/마켓플레이스 조사와 전체 기능 대조는
[`alt-feature-parity.md`](./alt-feature-parity.md)에 기록했다. 이 문서는 이전에 확인한 노트 상세
흐름과 Ravil의 초기 대응 내용을 유지한다.

2026-09-23에 설치된 Alt 앱을 Computer Use로 직접 열어 홈과 기존 노트 상세를 읽기 전용으로
확인했다. 사용자의 노트 내용은 수정하거나 공유하지 않았고 녹음·전사도 실행하지 않았다.

| Alt에서 실제로 본 구조 | 이번 Ravil 결정 |
|---|---|
| 왼쪽에 워크스페이스·과목 폴더·날짜별 노트 | Ravil 사이드바를 보관함·도구·과목·최근 노트로 나누고 강의 목록을 날짜별로 묶음 |
| 어두운 홈 중앙에 PDF/녹음 가져오기, 새 노트, 캘린더·플러그인 안내 | Ravil 홈의 첫 초점을 PDF 추가·노하우 기록·강의 다시 보기에 두고 어두운 화면을 기본값으로 설정. 캘린더·플러그인은 아직 구현되지 않아 표시하지 않음 |
| 홈 아래에 녹음 시작과 언어·컴퓨터 소리·키워드·화자 인식 설정 | Ravil 홈 아래에 녹음 시작 바를 고정하고 녹음 중 시간을 표시. 구현된 마이크 녹음·언어 자동 감지만 안내하고, 미구현 컴퓨터 소리·화자 인식 설정은 노출하지 않음 |
| 노트 상세 위쪽에서 `노트/요약` 전환 | 강의 상단을 편집 가능한 노트와 근거가 표시된 요약으로 분리 |
| 상세 아래 전사·오디오 재생바가 고정되고 화자·시각이 보임 | 상단 화면을 바꿔도 아래 전사와 재생바가 남고, 화자·시각을 눌러 원본 재생 |
| 요약에서 화자별 비율과 핵심 내용 | 제공된 화자 정보가 있을 때만 화자별 전사 길이 비율을 추정치로 표시 |

Ravil은 Alt의 정보 위계와 주요 진입 흐름을 참고하되 브랜드와 화면 구성 요소를 그대로
복제하지 않는다. 과목·강의·개인 노하우를 함께 검색하고, 각 강의의 개인 메모와 PDF를
Ravil의 저장소에 연결하는 방향을 유지한다. 어두운 화면은 설정에서 끌 수 있다.

Alt에서 실제로 확인한 화면과 Ravil의 수정 코드는 근거 수준이 다르다. 수정된 Ravil의
Swift 릴리스 빌드와 DB·전사·PDF 테스트, 마운트한 DMG 내부 앱의 헤드리스 전사는 별도로
확인했으며, 새 레이아웃의 실제 전경 화면 검수와 마이크 녹음 사용자 경로는 아직 미검증이다.
