# 현재 우선순위: Mac 성능·안정성

2026-10-01 사용자 결정. 최종 목표는 학생용 통합 학습 앱이지만, 현재 개발 단계는 **사용자의 Mac에서 기본 학습 흐름이 빠르고 안정적으로 작동하는 것**이다.

## 지금 집중할 범위

1. PDF 가져오기·열기·페이지 이동과 검색의 응답성.
2. 과목 폴더, 강의 기록, 메모, 자료 판본과 변경 이력 보존.
3. 녹음·전사·저장·재열기의 오류 복구와 데이터 보존.
4. 실제 Mac 사용 흐름에서의 검증과 설치·업데이트 안정성.

측정 결과를 먼저 확보하고 큰 지연부터 수정한다. 속도 향상을 위해 원본 PDF, 이전 판본, 전사 이력 또는 사용자 메모를 삭제하지 않는다.

첫 개선과 구성요소 측정 결과는 [Mac PDF 성능 기록](mac-performance-2026-10-01.md)에 정리한다.

## 후순위

- AI 자동 복습, 문제 생성, 학습 코칭 고도화.
- 추가 학습자료 확대와 다음 모델 가중치 학습.
- iPad·iPhone 네이티브 앱 공개.
- 다중 기기로 확장할 때는 PWA를 먼저 검토한다. PWA의 실제 기능·오프라인 범위·동기화 방식은 아직 결정·구현된 것으로 표시하지 않는다.

기존 시험 범위·수동 카드와 저장 데이터는 유지한다. 이번 결정은 개발 우선순위 조정이며 기존 사용자의 데이터를 삭제하는 변경이 아니다.

## Mac 우선 단계의 완료 기준

- 실제 자료량에서 PDF 작업과 검색 중 화면이 응답한다.
- 가져온 자료가 올바른 과목·강의에 저장되고 재열기 후에도 유지된다.
- 새 PDF 판본이 생겨도 이전 판본과 연결 근거가 보존된다.
- 실제 녹음→전사→저장→재열기를 확인한다.
- 빌드·헤드리스 검사와 실제 GUI 검증을 별도로 보고한다.

사용자가 작업 중인 화면은 명시적으로 맡긴 경우에만 조작한다. GUI 검증은 별도 검증용 앱·DB 사본으로 먼저 수행한다.
