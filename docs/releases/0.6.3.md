# Ravil 0.6.3 — Mac 성능 개선 미리보기

2026-10-01 · 앱 빌드 12 · Apple Silicon(arm64) · 사전 배포판

## 변경 사항

- 긴 PDF 가져오기의 파일 복사·해시·텍스트 추출을 백그라운드에서 처리한다. 가져오는 중 상태를 표시하고 중복 실행을 막는다.
- PDF 문서를 재사용하고 불필요한 이미지 직렬화를 없앴다. 페이지 이미지는 픽셀 비용 기준 32MiB 목표, 최대 4개 캐시를 사용한다.
- 가져오는 동안 다른 자료로 이동하면 완료 시 원래 화면으로 되돌리지 않는다.
- 과목 연결, 중복 방지, PDF 판본 이력과 검색을 유지한다.
- 계정 비밀 설정이나 검증용 보관함 경로가 들어간 앱은 DMG 포장을 거부한다.

462쪽 PDF를 사용한 구성요소 측정에서 페이지 표시 준비 평균은 51.9ms에서 20.3ms로 줄었다. 가져오기 전체 시간은 약 4.5–4.7초로 비슷했고, 10ms 메인 액터 타이머의 최대 지연은 4,498ms에서 26ms로 줄었다. 실제 GUI 클릭 지연이나 모든 기기의 성능을 보장하는 수치는 아니다. [측정 방법·재측정 결과](../mac-performance-2026-10-01.md).

## 다운로드와 설치 조건

- 파일: `Ravil-0.6.3-arm64.dmg`와 `SHA256SUMS.txt`.
- Intel Mac은 이번 설치판의 대상이 아니다. 빌드 최소 대상은 macOS 14이며, 실제 개발용 Apple Silicon Mac 외의 운영체제·기기 조합은 미검증이다.
- DMG에는 `Ravil.app`과 Applications 바로가기가 들어 있다. 기존 앱을 종료하고 보관함을 백업한 뒤 교체하는 개발용 미리보기다.
- **Developer ID 서명·Apple 공증이 없다.** ad-hoc 서명만 적용했고, 다운로드한 앱은 Gatekeeper에서 차단될 수 있다. 일반 사용자 배포 준비가 완료됐다는 의미가 아니다.
- 공개 앱에는 OAuth client secret과 사용자 토큰을 넣지 않았다. Google Drive 신규 로그인·동기화는 이 공개 설치판으로 검증하지 않았으며, 별도 개발자 OAuth 설정이 필요할 수 있다. [개발 환경 안내](../development.md).

## 포함되는 음성인식 모델과 출처

기본 모델은 OpenAI Whisper large-v3-turbo의 공개 GGML q5_0 양자화 파일이다. 이 설치판이 Ravil에서 새로 학습한 가중치를 포함한다는 의미는 아니다.

- 모델: OpenAI Whisper / ggerganov whisper.cpp 변환, MIT.
- 실행기: ggml-org whisper.cpp 소스 리비전 `6e4ab854f67f743900934a703d5603419384c961`, MIT.
- VAD: Silero VAD, MIT.
- 모델 카드, 고정 리비전·해시와 라이선스 원문을 앱에 포함했다. [제삼자 안내](../../THIRD_PARTY_NOTICES.md).
- 개인 녹음·학습지·전사·보관함 DB·추가 학습 어댑터는 포함하지 않는다.

## 검증 범위

- **Implemented:** PDF 백그라운드 가져오기, 직렬 페이지 렌더링·캐시, 진행 상태와 배포 설정 검사.
- **Unit-verified:** 생성한 PDF의 픽셀 일치, 캐시 무효화, 취소, 과목·중복·판본 이력·재열기, 잘못된 PDF 거부. 임시 DB의 저장·검색·재열기 검사도 통과했다. 실제 DMG 안의 앱으로 실행했다.
- **구성요소 검증:** DMG의 실제 번들 모델·VAD로 합성 한국어 음성에서 타임스탬프 전사 생성. 실수업 정확도 평가 및 마이크 녹음 검증과는 별개다.
- **Physical-device-verified (실행 범위):** 기존 개발용 Mac의 앱을 교체하고 재실행하여 기존 보관함 홈 화면을 확인했다. DB 개수와 무결성 확인, 이전 앱·DB 백업을 수행했다.
- **패키지 검증:** DMG 체크섬, 중첩 코드 서명, 모델·런타임 출처·해시와 외부 Homebrew 링크 부재를 검사했다. 설치본과 배포본 실행 파일의 코드·데이터 섹션도 일치했다. 로컬 계정 설정을 보존한 설치본과 공개본의 서명은 다르다.
- **Not verified / 미검증:** GUI의 PDF 가져오기·연속 페이지 이동, 실제 마이크 녹음부터 전사 저장·재열기까지, 공개판의 실계정 Drive 연동, 다른 Mac의 신규 다운로드·설치. 사용자 화면이 녹음으로 바뀐 뒤에는 추가 UI 조작을 중단했다.

AI 자동 복습, 추가 학습자료 확대, iPad·iPhone 네이티브 공개는 이번 범위에 포함되지 않는다. [Mac 우선 범위](../mac-first-roadmap.md).
