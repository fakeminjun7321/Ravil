# 첫 GitHub 소스 업로드의 범위 — 2026-10-01

Ravil Mac 앱과 공통 처리 패키지, 모델 실험 도구를 보관하는 첫 소스 스냅샷이다. **설치판 출시나 제품 전체 완료를 의미하지 않는다.** 앱의 소스 버전은 0.6.2이며 Ravil-ASMR의 실험 버전과 별개다.

## 포함 범위

- Mac 앱, 로컬 API, DB·가져오기·동기화·분류·자료 처리 코드.
- 로컬 전사 모델의 다운로드·평가·추가 학습 도구와 공개 가능한 집계 결과.
- 공개 설정 예제, 모델 출처·해시·라이선스 안내, 개발 환경과 검증 기록.

개인 녹음·전사·학습지·DB, 사용자 토큰·OAuth 비밀 파일, 모델·학습 어댑터 가중치, 앱/DMG, 로컬 실험 폴더는 포함하지 않는다. 기존 개인 운영 기록과 별도 제작 중인 소개 사이트는 이번 커밋의 범위가 아니다. 로컬 원본은 보존했다.

## 이번 검사

- **Implemented:** 위 소스와 개발 문서가 존재한다.
- **Unit-verified:** `npm test`의 Ravil 검사 16개, Python ASR 검사 22개 통과. Node 검사 범위를 `test/*.test.mjs`로 제한해 임시 폴더에 받은 외부 프로젝트의 검사를 잘못 실행하던 문제를 수정했다.
- **Build-verified:** Apple M5에서 `swift build --sdk /Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk --scratch-path tmp/github-verify/swift` 성공. 기존 unused-value 및 Command Line Tools 검색 경로 경고가 있으며 빌드 실패는 없었다.
- **Headless local check:** 새로 빌드한 실행 파일의 `--smoke-test` 통과. 임시 DB와 예제 데이터를 사용해 저장·재조회·이력·가져오기 등을 검사했다. 실제 마이크 녹음이나 외부 계정 연동 시험은 아니다.
- **업로드 파일 검사:** 스테이징된 파일에서 개인 데이터·대형 모델·키 파일 유형과 알려진 토큰/비밀값 패턴을 검사했다. 모델용 `.env` 두 파일은 공개 URL·리비전·해시만 포함하는 설정이다. OAuth client ID는 공개 앱 식별자이며 client secret이나 사용자 토큰은 포함하지 않는다. 전체 보안 감사 또는 법적 적합성 보증은 아니다.

**Not verified / 미검증:** 설치 GUI의 전체 녹음→전사→검색·재열기, 실계정 Drive 동작, 모든 OCR 정확도, 기기 간 동기화, 다른 Mac 설치, Developer ID 공증·일반 사용자 배포. 해당 단계가 끝나기 전 다운로드 가능한 정식 제품으로 표시하지 않는다.

## 학습 실험 정리

첫 Qwen LoRA 실험은 가중치 변경·저장·재로드까지 수행했으나 한국어 비퇴행 기준을 통과하지 못했다. [0.6 파일럿 기록](ravil-asmr-0.6-training-pilot.md)에 집계 결과를 보존했다. 추가 공개 학습자료 작업과 다음 학습은 사용자의 요청에 따라 보류했다.
