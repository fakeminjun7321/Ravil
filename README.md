# Ravil

**내가 자유롭게 남긴 기록을 AI가 분석하고 정리하며, 필요한 순간에 생각과 행동을 돕는 개인용 세컨드 브레인 워크스페이스**입니다.

메모, 생각, 경험, 아이디어, 자료와 계획을 기록하고 주제·프로젝트로 연결합니다. AI는 관련 기록을 근거로 핵심을 정리하고 질문에 답하며 다음 행동을 제안합니다. 원문과 사용자의 정정은 보존하고, AI의 해석은 확인하고 수정할 수 있는 별도 결과로 다룹니다. 공부와 강의 기록은 이 공간의 활용 영역 중 하나입니다.

제품 판단의 기준은 [개발 목표](docs/product-goal.md), 구현 순서는 [공식 로드맵](docs/canonical-roadmap.md)입니다.

현재는 **개발·검증 중인 제품**입니다. Apple Silicon용 [0.6.3 미리보기 설치판](https://github.com/fakeminjun7321/Ravil/releases/tag/v0.6.3)을 제공합니다. Apple 공증과 다른 Mac의 신규 설치 검증은 아직 없으며, 정식 출시판이 아닙니다. [설치판의 검증 범위와 제한](docs/releases/0.6.3.md)을 먼저 확인하세요.

공개된 0.6.3 설치판의 기능 범위는 당시 릴리스 문서를 따릅니다. 새 목표에 맞춘 변경은 현재 작업 소스에서 개발하며, 배포된 설치판의 업데이트는 별도 검증·배포 단계입니다.

현재 개발의 중심은 **기록 → AI 분석·정리 → 다시 찾고 활용하기**입니다. Mac과 웹에서 원문 보존·저장·재열기·출처 연결의 안정성을 먼저 확인합니다. 기기 확장은 PWA부터 검토합니다. [Mac 개발 범위](docs/mac-first-roadmap.md)를 참고하세요.

## 구성

- **개인 작업 공간:** 원문 기록, 주제·프로젝트 연결, 자료 첨부, 검색, 할 일과 활동 기록.
- **AI 도움:** 선택 기록과 관련 기록에 근거한 정리·질문·연결·다음 행동 제안. 외부 AI 연결과 모델의 실제 품질은 따로 검증합니다.
- **Mac·웹·클라우드:** SwiftUI 앱, 웹·PWA, 계정별 저장·동기화·백업.
- **자료 처리:** PDF·판본, OCR, 녹음·전사, 기존 Alt 기록 가져오기. 학습 흐름도 이 기반을 활용합니다.
- **Ravil-ASMR 실험:** 공개 모델을 기반으로 한 전사 최적화·추가 학습 실험. 제품 목표를 달성하는 입력 수단 중 하나이며 별도로 검증합니다.

```
apps/macos/    SwiftUI macOS 앱
apps/website/  웹·PWA 개인 작업 공간과 소개
apps/cloud/    계정·동기화·파일·AI·백업 API
apps/api/      로컬 API 실험
packages/      DB·가져오기·동기화·분류·자료 처리
src/           초기 가져오기·분석 도구
script/        빌드·포장·모델 다운로드·평가·학습 도구
config/        공개 설정 예제와 모델 출처·라이선스 기록
test/          Node 및 Python 검사
docs/          개발 환경·검증 상태·모델 실험 기록
```

## 개발과 검사

Node.js 24 이상과 macOS용 Swift 도구가 필요합니다.

```sh
npm test
swift build
```

앱 번들, 로컬 전사 모델, Google OAuth 설정과 SDK 문제는 [개발 환경 안내](docs/development.md)를 참고하세요. 녹음·PDF·전사·DB·모델 가중치·OAuth 비밀값은 저장소에 포함하지 않습니다.

## 라이선스와 출처

Ravil 자체 코드의 외부 이용·배포 라이선스는 아직 결정하지 않았습니다. 이 저장소를 오픈소스 이용 허락으로 해석하지 마세요. 외부 모델·라이브러리의 라이선스는 각각 적용됩니다. [제삼자 구성요소 안내](THIRD_PARTY_NOTICES.md)와 `config/`의 모델 카드를 확인하세요.

Ravil-ASMR은 공개 기반 모델을 활용하는 프로젝트입니다. 기반 모델까지 처음부터 직접 학습했다고 주장하지 않으며, 추가 학습·변환·실행 최적화의 범위를 구분해 기록합니다.
