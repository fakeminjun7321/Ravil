# RAVIL 소개 사이트

기준: 사용자가 승인한 ALTALT.io 참고안. 한국어 학생용 제품 소개이며, 현재 개발 상태를 알린다.

추가 지시: ALTALT.io를 많이 참고하고 OpenAI.com도 참고한다. 두 사이트의 실제 첫 화면과 아래 구간을 숨김 브라우저에서 확인했다.
- ALT: 가운데 제목·주요 버튼, 큰 인터랙티브 앱 데모, 기능·제작 이야기로 이어지는 흐름을 주된 기준으로 유지한다.
- OpenAI: 단순한 상단 탐색, 큰 여백, 흰 바탕과 검은 대표 구간, 제목과 날짜가 분명한 편집형 소식 구성을 개발 소식 페이지에 적용한다.
- 양사 로고·콘텐츠·제품 성능·고객사를 가져오지 않는다.

## 시안과 구현 기준

Image Gen으로 생성한 구간별 시안: `01-hero-demo.png`, `02-flow-features.png`, `03-story-faq.png`.
실제 웹사이트는 이미지에 텍스트를 입히지 않고 HTML과 CSS로 구현한다.

- 바탕 #f7f8f5, 글자 #232622, 보조 글자 #666b63, 강조 #d9f18b.
- Pretendard 한글/영문. 큰 제목 72px, 구간 제목 44–52px, 본문 18px, UI 14px, 작은 보조 문구 12–14px.
- 최대 폭 1280px, 기본 좌우 여백 40–56px. 모바일 20px.
- 큰 제목, 열린 3열 사용 흐름, PDF 판본 구간의 넓은 강조 면, 2열 기능 예제, 열린 FAQ, 어두운 마지막 구간.
- 제품 데모는 과목과 자료 목록을 중심으로 한 실제 앱 구조를 참고한 공개용 예제다. 웹 앱이나 실물 앱 검증 증거가 아니다.
- 효과는 호버·탭 전환 위주. reduce-motion을 존중한다.

## 시안의 의도적 조정

- 02 시안이 임의로 추가한 상단 메뉴와 성능·자동 연결 암시를 제거하고 승인된 메뉴 및 실제 기능 범위로 맞춘다.
- 03 시안이 임의로 추가한 앱 홈 화면(자료구조·운영체제·데이터베이스, 가상의 파일 수)은 제품 구조와 다르므로 사용하지 않는다. 승인한 개발 이야기와 FAQ는 유지한다.
- 시안의 임의 연도는 2026년 공개용 예제 날짜로 맞춘다.
- 제품 데모의 파일 선택·강의 검색·답 보기·다음 카드가 실제로 반응하도록 구현한다. 앱 기능의 실제 서비스 실행으로 설명하지 않는다.
- 다운로드는 제공하지 않으며 공개 배포 일정은 미정이다. 연락처를 임의로 만들지 않는다.

## 소개 내용 확장

사용자 요청: 사이트 내용이 부족하므로 더 늘린다. 기존 첫 화면과 제품 데모는 유지하고 실제 활용 설명을 채운다.
구간별 새 시안: `04-study-situations.png`, `05-search-data.png`, `06-feature-detail.png`.

- 홈페이지 7구간에서 11구간으로 확장: 활용 상황, 통합 검색 예제, 데이터 처리 원칙, 개발 글 목록.
- 콘텐츠 페이지 4개에서 8개로 확장: 기능 상세와 개발 글 3개 추가. 404는 이 수에 포함하지 않는다.
- 기능 상세는 과목 보관함, 강의 기록, PDF 판본, OCR 대조, 노트·검색, 시험 범위·복습 6개를 다룬다.
- FAQ 4개에서 8개로 확장하고 사용·데이터 안내 및 사이트맵을 함께 갱신한다.
- 시안이 임의로 넣은 오디오 재생 컨트롤과 AI 자동 퀴즈 생성은 구현 상태를 오인하게 하므로 넣지 않는다.
- 원문 대조 예제는 실제 OCR을 실행하지 않는다. 데이터 처리를 설명한 시안의 자동 요약·완전한 오프라인 암시는 실제 범위에 맞게 수정한다.

제목, 구간 배치, 한글 위계, 색상, 제품 예제의 표면·아이콘을 시안과 실제 렌더에서 대조했다.
3열 예제 프레임의 높이를 맞추고 인식문 입력란에도 Pretendard를 명시했다.
기존 제품 데모, 통합 검색·결과 펼치기, OCR 예제 대조·초기화, 새로고침 초기화, 모든 내부 링크를 검사했다.
1440·768·390·320px에서 홈·기능·소식·개발 글의 가로 넘침을 확인했다. 실물 모바일·Safari 검증은 별개다.
