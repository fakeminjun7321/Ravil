## 의도적 차이

- 작품 외의 임의 영문 문구·책·새 자료 내용을 넣지 않았다.
- 로그인에서는 장식적인 실내 소품을 줄이고 작품과 실제 폼에 집중했다.
- 작업 본문은 16px/1.95, 버튼은 12–14px. 일반적인 편집 밀도를 유지하며
  실제 할 일이 추가되면 기록지가 이어진다. 시안처럼 종이를 고정 높이로 잘라 결과를 숨기지 않는다.
- 제품 데모의 자료 구조와 수식은 기존 공개 예제를 따른다.
- IAB에서 크기 변경 후 클릭 위치가 불안정한 경우 기본 크기로 돌려 실제 조작을 확인했다.
  모바일 검수는 화면 크기 렌더이며 실제 iPhone·iPad 검증으로 설명하지 않는다.

## 검증 수준

- Implemented: 웹 소개, 로그인·가입, 작업 화면의 공통 디자인과 두 미술 자산.
- 타입 검사: Astro, Pages Function, Worker 통과. 웹 빌드 통과.
- 로컬 사용자 경로: 소개의 로그인 링크 → 가입 → 작업 공간 진입, 과목·시험 프로젝트 생성,
  실제 공부 계획 저장 → 6개 할 일과 2회·3회 반복 보존, 완료 체크 1/2 표시,
  기록 목록과 재열기 확인. 원문 본문은 변경하지 않았다.
- 시각 검수는 구도·한글·색·재질·버튼·모바일을 기준으로 수행했다.
- Not verified: 실제 iPhone·iPad 설치·로그인, Mac 앱 디자인 변경(요청 범위에서 제외),
  기존 운영 사이트 반영(승인 대기).

운영 사이트 직접 요청 0회. 미리보기 배포 및 최종 클라우드 확인은 프로젝트 문서에 기록한다.
