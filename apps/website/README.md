# RAVIL 소개 사이트와 웹 작업 공간

ALTALT.io의 대형 제품 데모·기능 소개 흐름과 OpenAI.com의 단순한 탐색·편집형 소식 레이아웃을 참고한 한국어 소개 사이트.
기존 Astro 소개 사이트를 유지하면서 `/workspace/`에 개인 작업 공간을 이어 붙인다.
상단·모바일 메뉴의 ‘로그인’으로 계정에 들어간 뒤 같은 사이트의 `/workspace/`를 사용한다.
로그인한 상태에서는 메뉴가 ‘내 작업’으로 바뀐다. 작업 주소를 직접 열어도 서버가 세션을
확인하고, 로그인하지 않았으면 `/login/`으로 보낸다.
기존 공개 데모와 개발 글은 기존 주소를 사용한다.

## 과목 노트

작업 공간은 노트·공부 계획·활동 기록을 구분한다. 새 문단에서 `/h2`, `/표`, `/수식`,
`/PDF`로 블록을 넣거나 `+` 아이콘의 검색 메뉴를 사용한다. 글을 선택하면 작은 서식 도구가
표시되고 표 안에서만 행·열 도구가 나타난다. 같은 원본을 과목과 프로젝트에 함께 연결한다.
문법을 직접 입력할 필요는 없으며 저장 본문은 Markdown으로 호환성을 유지한다.
이전 일반 텍스트는 수정하기 전까지 그대로 보존하고, Obsidian 특수 문법을 포함한
가져온 파일은 원문 모드에서 편집한다. `.md`, `.markdown`, `.txt` 가져오기를 지원한다.

`/PDF` 또는 사진 아이콘은 PNG/JPEG/WebP 사진이나 PDF를 계정별 비공개 파일로 보관한다.
PDF는 첫 페이지를 노트에 표시하고 전체 원본을 연결한다. 파일당 최대 20MB이며,
이미지를 인식된 텍스트로 바꾸거나 OCR 결과를 만드는 기능은 이번 범위에 포함하지 않는다.

상단 내려받기 아이콘에서 Letter/A4와 PDF, DOCX, Markdown을 선택한다.
생성된 파일은 계정으로 보호되는 HTTPS 주소에서 내려받는다. 링크는 1시간 유효하며
만료된 출력 파일은 정리 작업으로 제거한다. 원본 노트와 첨부는 기존 보관 구조를 사용한다.
출력 파일은 최대 64MB이며 원본 첨부의 파일당 한도는 20MB다.
PDF에는 본문과 사진, 첨부 PDF의 전체 원본 페이지가 들어간다. DOCX의 글·표·기본 수식은
편집 가능한 문서 요소이며 사진과 첨부 PDF는 이미지로 들어간다. 복잡한 수식은 모양을
보존한 이미지로 출력한다. 한글 글꼴은 파일에 포함한다. Markdown 출력은 첨부가 있을 때
원본 PDF까지 포함한 ZIP으로 내려받는다. Google Docs 계정 연결이나 DOCX 가져오기는
별도 기능이다. 출력에 사용한 Nanum Gothic 글꼴의 OFL은 `public/note-fonts/OFL.txt`에 있다.

노트 저장은 계획 할 일을 만들지 않는다. ‘공부 계획’으로 선택하거나 ‘계획으로 정리’를
누르면 기존 날짜·행동·반복 횟수 추출을 사용한다.
검증 범위와 생성 파일은 `../../docs/subject-notes-2026-10-05.md`에 기록한다.

현재 시각 방향은 입체 조각과 기록지의 재질을 사용하는 개인 작업실이다.
`design/art-2026-10-05/DIRECTION.md`에 시안·자산·디자인 시스템,
`QA.md`에 실제 렌더와 의도적 차이를 기록한다. 기존 `design/DIRECTION.md`는 초기 소개 사이트 이력이다.

페이지: 소개 `/`, 기능 상세 `/features/`, 개발 소식 `/updates/`, 사용 안내 `/guide/`, 데이터 안내
`/privacy/`, 개발 글 3개 `/journal/`, 로그인 `/login/`, 가입 `/signup/`, 개인 작업 공간 `/workspace/`. 홈페이지에는 수업 중·수업 후·시험 준비 활용 상황과
로컬 보관·기기 내 처리·외부 연결의 차이를 설명한다.

## 로컬 작업

Node 24 이상에서 `npm ci`, `npm run dev`. 기본 주소는 `http://127.0.0.1:4321`.
`npm run check`, `npm run build`, `npm run preview`로 정적 빌드 검수.

로그인·저장까지 연결한 로컬 검증은 `apps/cloud`에서 Wrangler 개발 서버를 실행한 뒤
이 디렉터리에서 `npm run dev:connected`를 사용한다. Pages 개발 서버 주소는
`http://127.0.0.1:8789`. 클라우드 개발 서버의 `APP_ORIGINS`에 이 주소를 명시한다.
`astro dev`나 `astro preview`만으로는 `/api/` 기능이 제공되지 않는다.

## 배포

Cloudflare Pages 프로젝트 `ravil-website`. `npm run deploy:preview`는 workspace-preview 브랜치,
`npm run deploy`는 main 브랜치로 배포한다. 기존 Wrangler 로그인을 사용한다.
CI용 토큰을 생성하거나 저장하지 않는다.

미리보기의 고정 주소는 `https://workspace-preview.ravil-website.pages.dev`이며
기존 공개 주소는 `https://ravil-website.pages.dev`. 운영 반영은 검수 후 사용자 승인으로 진행한다.

`functions/api/[[path]].ts`는 `/api/*`만 비공개 서비스 바인딩 `WORKSPACE_API`로
`ravil-workspace-preview` Worker에 전달한다. 브라우저를 다른 사이트로 이동시키지 않는다.
로그인 쿠키는 접속한 Pages 주소에 보관되며 서버는 배포 설정에 명시한 주소만 허용한다.
Mac은 같은 Worker와 D1/R2를 사용하므로 같은 계정으로 기록을 이어 쓸 수 있다.
`functions/workspace/[[path]].ts`는 작업 공간의 로그인 세션을 검사한다.
소개·로그인 화면·공개 데모는 정적 자산으로 제공하며 `_routes.json`은 API와 보호된
작업 공간만 함수에 보낸다. 로그인 확인 전에 계정별 IndexedDB 기록을 표시하지 않는다.
작업 HTML은 `private, no-store`로 제공하고 PWA가 로그인 우회를 위한 이전 HTML을
캐시하지 않게 한다. 새로 작업 공간을 열 때는 연결이 필요하며, 이미 열린 화면에서
작성 중 연결이 끊기면 수정은 기기에 임시 저장한다.

Wrangler 4.145.0은 새 Pages 프로젝트를 Workers로 자동 전환할 수 있다. 스크립트의 `--force`는
Wrangler에서 제공하는 Pages 직접 배포 옵션이며, 검수한 정적 설정을 유지하기 위해 명시했다.
기존 Pages 프로젝트는 Cloudflare API로 생성했다. 새 작업 공간의 D1/R2와 인증은
`apps/cloud` Worker가 담당한다. 이 사이트에 인증 비밀값을 복사하지 않는다.

현재는 직접 업로드 방식으로 미리보기를 배포한다. GitHub 저장소는 웹사이트 전용 비공개 소스 보관용이다.
GitHub 연결 또는 CI 배포 인증은 아직 구성하지 않았으므로 push만으로 자동 배포되지는 않는다.

Git 연결을 사용하는 경우 빌드 명령 `npm ci && npm run check && npm run build`, 출력 디렉터리 `dist`,
프로덕션 브랜치 `main`, Node `24`. 웹사이트 전용 저장소에서는 루트 디렉터리가 `/`이다.
현재 앱 저장소 전체를 업로드하지 말고 이 디렉터리의 웹사이트 소스만 사용한다.

도메인을 바꾸면 `astro.config.mjs`, `public/robots.txt`, `public/sitemap.xml`의 주소를 함께 수정하고 재배포한다.
맞춤 도메인 구매·DNS 변경은 이 작업에 포함하지 않는다.

## 콘텐츠와 검증 범위

- 실제 사용자 자료는 포함하지 않는다. 데모는 앱 사용자 경로 검증 증거가 아니다.
- 현재 개발 중이며 공개 다운로드·출시일·지원 기기·성능 수치를 임의로 확정하지 않는다.
- 공개 데모의 검색어와 인식문 수정은 브라우저 메모리에서만 처리한다.
- 작업 공간은 기기별 IndexedDB, 이메일·비밀번호 로그인, 계정별 클라우드 저장을 사용한다.
  RAVIL 안의 활동만 개인화에 사용하며 Google Calendar와 알림은 별도 연결이 필요하다.
- 인식문 대조는 고정 원문 예제와 공백을 제외한 문장이 같은지 확인하는 웹 예제다. 실제 OCR·AI 추론이 아니다.
- 글꼴: Pretendard 1.3.9, SIL OFL 1.1. `public/font-license.txt`에 라이선스를 보존한다.
- 구간별 생성 시안과 변경 사유는 `design/`에 있으며 배포 산출물에는 포함하지 않는다.

소개 사이트의 화면·링크·탭 검증과 macOS 앱 설치·녹음·전사·동기화 검증을 구분한다.
